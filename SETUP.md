# Setup — Loreeenzz profile

1. Create or open the **public** repository `Loreeenzz/Loreeenzz` (https://github.com/Loreeenzz/Loreeenzz). Back up any existing README before replacing it.
2. Copy `README.md`, `assets/`, `profile-3d-contrib/`, and `.github/` into the repository root. Do not nest them inside another folder. Keep the hidden `.github` directory.
3. In `README.md`, replace each `https://sample.com` with the corresponding real LinkedIn, portfolio, Facebook or Instagram URL (each occurs twice). Confirm your email, company/project references and availability are appropriate for a public profile.
4. Commit and push to your default branch. Enable Actions in the repository if necessary. Under Settings > Actions > General, make sure the selected third-party actions are permitted and workflow write access is allowed by repository/organization policy.
5. Open **Actions > Update profile graphics > Run workflow** on the default branch. Review each step's log. After a successful run, local placeholder images are replaced by generated SVGs and committed automatically. The workflow repeats daily at 00:17 UTC (08:17 Philippines time). No personal access token is required for the intended public data.
6. Check the public profile at https://github.com/Loreeenzz in light and dark themes. If the workflow cannot push, check branch protection and workflow permissions. If a generator fails, the other generators can still run; check the step warnings and rerun when resolved.

## Git option (new empty profile repository only)

Run these inside the extracted folder, after editing the links. If the repository already has content, clone it first and copy these files in instead of creating unrelated history.

```bash
git init -b main
git add README.md assets profile-3d-contrib .github
git commit -m "feat: personalize GitHub profile"
git remote add origin https://github.com/Loreeenzz/Loreeenzz.git
git push -u origin main
```

## Notes

- The package includes editable light and dark animated SVG headers. GitHub rendering may differ from local rendering, and some clients suppress SVG animation.
- Snake, 3D calendar, and top language cards are generated by Actions; the included placeholder images are intentionally labeled and contain no fabricated data. The 3D action's standard light palette is green; the dark version is its night view preset.
- Skill Icons, Shields.io, GitHub Profile Trophy, GitHub Readme Activity Graph, and Komarev are external services. Their uptime, caching, rate limits, and data coverage can vary. Trophy badges are third-party metrics. The counter measures requests/profile views rather than unique people.
- The included workflow uses upstream release/major tags and the repository's built-in token. For stronger supply-chain security, audit and pin actions to full commit SHAs before use. No secrets are embedded. This package has not been executed in your GitHub account.
- Scheduled workflows on inactive public repos may be automatically disabled by GitHub. Re-enable if needed.
- Public contribution settings may influence what graphs show. Do not add broad private-repository access without reviewing the data disclosure implications.
- No project-specific metrics or public repository links were invented. Add your own verified project links and results later.
